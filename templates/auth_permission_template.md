## 3. 后端校验点

- [ ] 每个受保护接口都校验登录态
- [ ] 每个管理接口都校验角色或权限点
- [ ] 每个数据读取 / 修改接口都校验数据归属
- [ ] 前端隐藏按钮不等于后端授权
- [ ] Token、密码、验证码、Session 不进入日志

## 4. 测试场景

| 场景 | 预期 |
|---|---|
| 未登录访问受保护接口 | 401 |
| 普通用户访问管理员接口 | 403 |
| 用户访问他人数据 | 403 或空结果 |
| Token 过期 | 要求重新登录或刷新 |
