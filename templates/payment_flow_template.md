# 订单支付流程模板

## 1. 订单状态机

| 状态 | 含义 | 可进入状态 | 触发动作 | 是否终态 |
|---|---|---|---|---|

## 2. 支付单状态机

| 状态 | 含义 | 可进入状态 | 触发动作 | 是否终态 |
|---|---|---|---|---|

## 3. 必须字段

| 表 | 字段 | 用途 |
|---|---|---|
| orders | order_no | 业务订单号，唯一 |
| payment_records | payment_no | 支付单号，唯一 |
| payment_records | provider_trade_no | 第三方交易号 |
| payment_records | idempotency_key | 幂等键 |
| payment_records | paid_amount | 实付金额 |
| payment_records | callback_raw | 回调原文或摘要 |

## 4. 回调处理流程

1. 接收回调，但不信任回调内容。
2. 验证签名、商户号、订单号、金额、币种、状态。
3. 使用支付单号或第三方交易号做幂等判断。
4. 在事务中更新支付单和订单状态。
5. 重复回调直接返回成功，不重复发货或重复记账。
6. 记录原始回调摘要和处理结果。
7. 异常进入补偿队列或人工处理清单。

## 5. 测试场景

| 场景 | 输入 | 预期 |
|---|---|---|
| 正常支付成功 | 合法回调 | 订单已支付 |
| 重复回调 | 同一支付单再次回调 | 不重复处理 |
| 金额不一致 | 回调金额被篡改 | 拒绝处理并告警 |
| 签名错误 | 非法签名 | 拒绝处理 |
| 超时未支付 | 超过关闭时间 | 订单关闭 |
| 支付后退款 | 退款成功回调 | 状态一致 |
