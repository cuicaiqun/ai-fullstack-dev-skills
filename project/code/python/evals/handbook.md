# AgentHub 员工知识手册（评测用）

## 差旅报销

员工因公出差产生的交通、住宿费用，须在返回后 **7 个自然日** 内提交报销单。
单次住宿标准：一线城市不超过 **600 元/晚**，二线城市不超过 **400 元/晚**。
超标部分需附部门负责人书面说明，否则不予报销。

## 设备申请

新入职员工默认发放笔记本电脑一台。额外显示器或外设需走 IT 门户工单，审批人为直接上级。
工单 SLA：**3 个工作日** 内完成发放或给出替代方案。

## 知识库系统

公司内部知识问答系统代号 **AgentHub**，检索同时使用向量库与 Neo4j 知识图谱。
文档入库后默认租户可见；涉密文档须设置为 private，仅所有者与 admin 可检索。
