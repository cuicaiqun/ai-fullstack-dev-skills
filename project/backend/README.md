# backend：后端真实项目代码区

这里用于放置后端服务代码，例如 Node.js、Java、Python、Go、PHP 等后端项目。

硬规则：

- 后端真实代码只能放在 `project/backend/`。
- 不要把后端业务代码写入 `skills/05_backend/`，那里只放后端开发 Skill。
- 不要把后端业务代码写入 `examples/` 或 `templates/`。

建议后续结构示例：

```text
project/backend/
├── src/
├── tests/
├── package.json 或 pom.xml / requirements.txt
├── .env.example
└── README.md
```
