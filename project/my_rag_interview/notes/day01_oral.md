# Day 1 口述卡（可打印）

## 30 秒版

企业知识库 RAG：文档入库 → 检索增强问答 → 变更增量更新。  
FastAPI 做入口，LangGraph 做编排，Agent 做解析/问答/更新，底层是向量库和图谱。

## 追问快答

**Q: 为什么不让 FastAPI 里直接写检索？**  
A: 接口层应保持薄；换检索策略、加重试/分支时不应和 HTTP 细节耦死。

**Q: LangGraph 是干什么的？**  
A: 把多步骤流程建成图：顺序、条件边、重试、状态传递；比长 if-else 好维护。

**Q: 没有向量库能问答吗？**  
A: 能调 LLM，但不接地（ungrounded），容易瞎编；企业场景通常要 sources。

**Q: mock 接口的意义？**  
A: 先冻结 API 契约和联调路径，再替换内部实现，降低一次集成太多变量的风险。
