# frontend：前端真实项目代码区

这里用于放置前端代码，例如 Vue、React、Next.js、Nuxt、H5、uni-app、小程序等。

硬规则：

- 前端真实代码只能放在 `project/frontend/`。
- 小程序原生代码默认放在 `project/frontend/miniprogram/`。
- 不要把前端业务代码写入 `skills/06_frontend/`，那里只放前端开发 Skill。
- 不要把前端业务代码写入 `examples/` 或 `templates/`。

建议后续结构示例：

```text
project/frontend/
├── src/
├── public/
├── package.json
├── .env.example
└── README.md
```
